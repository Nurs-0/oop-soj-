СӨЖ 1 — Инкапсуляция қағидаттарына негізделген класс жобалау
ТАӘ: Ермахамбет Нұрасыл Әділханұлы
Топ: ПИ-01
Нұсқа: № 3 — Банктік шот (BankAccount)
Код бойынша қысқа түсінік
BankAccount класы банктік шотты сипаттайды: иесінің аты, шот нөмірі,
баланс. Барлық өрістер private, геттер/сеттер арқылы қол жеткіземін —
инкапсуляция осылай сақталады.
Транзакциялар тарихы (transactionHistory) динамикалық жадыда
(new double[...]) сақталады. Көшірме конструктор мен operator=
бұл массивті терең көшіреді (deep copy) — жаңа жад бөлініп, мәндер
көшіріледі, сондықтан бір объектіні өзгерту екінші объектіге әсер
етпейді.
Кемінде екі геттер (getOwnerName, getBalance) const деп
жарияланған, сондықтан const BankAccount объектісінде де шақыруға
болады.
operator= өзін-өзіне меншіктеуден қорғайды және ескі жадты босатып,
жаңасын бөледі. operator== шарты бойынша: екі шоттың нөмірлері
бірдей болса, объектілер тең деп есептеледі.
